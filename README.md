# 林さんになる動画チェッカー

林さんと bird and insect の YouTube 動画を、見た・見てないでチェックできるリストです。

- チャンネルごとにタブで切り替え
- 見た動画にチェック（このブラウザの中に保存。サーバーには送りません）
- ライブ配信のアーカイブも「ライブ」の印つきで一覧に入っています
- 「まだ／見た」での絞り込み、動画名の検索、新しい順・短い順などの並べ替え
- のこり本数と、のこり時間の合計を表示

## 構成

ビルド不要の静的サイトです。`index.html` をそのまま GitHub Pages で配信します。動画の一覧は `index.html` の中に入っています（2026年11月24日時点の「動画」タブと「ライブ」タブの内容。ショートは含みません）。

手元で確認するとき：

```bash
python3 -m http.server 8000
```
